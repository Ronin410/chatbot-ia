01 · Diagrama de flujo

De un mensaje a una respuesta

El mismo chatEngine atiende los dos canales. Adentro arma el prompt, consulta RAG y las acciones solo si el nivel del cliente las tiene activas, llama al modelo, y devuelve el texto para que cada canal lo entregue a su manera.

02 · Diagrama de proceso

Cómo se agenda una cita sin que el bot se equivoque

De las dos acciones de Premium, consultar_pedido solo lee. crear_cita escribe, así que sigue un proceso de dos vueltas: la primera nunca toca la base, la segunda solo se ejecuta si el usuario confirmó explícitamente.

03 · Diagrama de infraestructura

Qué corre dónde

Todo el paquete vive en dos contenedores de un mismo docker compose. El navegador, WhatsApp/Twilio y los proveedores de IA están del otro lado de internet — nunca corren en tu servidor.
